🍁 Canada ID v0.1.0

Unified Canadian AAMVA PDF417 barcode encoder, decoder, and card compositor

🔍 Decode

Upload any image containing a Canadian PDF417 barcode to instantly extract and parse all AAMVA fields — name, DOB, address, licence class, and more.

✏️ Encode

Generate a valid PDF417 barcode from a JSON payload for any province or territory. Province mismatches are auto-corrected, not blocked.

✅ Validate

Check your AAMVA field data against province-specific rules. Detailed per-field error and warning messages guide corrections.

📋 History

All encode, decode, and validate operations are persisted locally to an SQLite database and available for review at any time.

⚙️ Installation & Usage

# Install from source
git clone https://github.com/genXstark/canada-id.git
cd canada-id
pip install -e ".[web]"

# Launch the web UI
python -m canada_id.web

# Or use the CLI
canada-id --help

📦 Features

Standards

  • AAMVA DL/ID Card Design Standard 2020 (v10)
  • PDF417 barcode encoding & decoding
  • All 13 Canadian provinces & territories
  • Province-specific IIN & field rules

Web UI (Gradio)

  • Image upload for barcode decoding
  • JSON field editor with sample data
  • Auto province detection from fields
  • Operation history with filtering

CLI

  • canada-id decode <image>
  • canada-id encode <province> <fields.json>
  • canada-id validate <province> <fields.json>
  • Machine-readable JSON output
