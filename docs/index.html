🍁 Canada ID

Unified Canadian AAMVA PDF417 barcode encoder, decoder, and card compositor. All 13 provinces & territories supported.

GitHub Repository Documentation
📊

Encode & Decode

Generate and read PDF417 barcodes following the AAMVA standard used on Canadian driver's licences.

🗂️

Card Compositor

Overlay barcodes onto card templates with precise placement and rotation controls.

🌐

Web UI & CLI

Gradio-powered web interface plus a full-featured CLI. Desktop app available via PyInstaller.

🛡️

Validation Engine

Province-aware field validation catches data mismatches, format errors, and missing fields.

📋

MRZ Support

Generate and parse Machine Readable Zone (TD1/TD2/TD3) strings from AAMVA data.

📜

Full Audit History

Every operation is logged to a local SQLite database with timestamps, field data, and images.

Quick Start

# Install from source
pip install -e ".[web]"

# Launch the web UI
python -m gradio canada_id.web

# CLI: decode a barcode image
canada-id decode barcode.png --format json

# CLI: encode AAMVA data to barcode
canada-id encode --province ON --fields data.json -o barcode.png

# CLI: validate field data
canada-id validate --province AB --fields data.json

# CLI: generate MRZ
canada-id mrz --fields data.json --format TD1
